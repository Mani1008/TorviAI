# YC Sprint 1 — Demo script

Record this path for design partners / YC interview prep (Windows desktop app).

## Setup

1. Sign in and open the dashboard.
2. Settings → Integrations → connect **Gmail** (Desktop OAuth client in `.env`).
3. Click **Sync now** — Context Memory should show `gmail` / email chunks.
4. Use the product while viewing a support-related page (refund policy doc, Zendesk, Slack) so screen capture adds chunks.

## Distill → Confirm

1. Open **Skills & Policies** in the sidebar.
2. Click **Propose from recent context**.
3. Review draft policies/processes/skills.
4. Confirm at least one refund/exception-related skill or policy.
5. Optionally **Export confirmed** JSON for a design partner.

## Chat proof

1. Ask Torvi (overlay or chat):  
   *“How do we handle refunds under $50?”*
2. Confirm the answer cites the confirmed Company Brain skill/policy (prefer structured knowledge over raw dumps).

## Narration line

> Torvi is a company brain for support ops — we capture how work actually happens (screen + Gmail), compile skills you confirm, and inject them into every answer.
